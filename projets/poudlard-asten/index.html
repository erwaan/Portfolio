Escape Game « Poudlard × Asten »

Un escape game familial immersif sur le thème de l'admission à Poudlard, conçu pour l'entreprise Asten.

Le projet

Pour le Noël du CE de l'entreprise « Groupe Asten », j'ai créé un escape game multijoueur pour les familles, d'environ 30 minutes au total. L'histoire : vous avez reçu une lettre de convocation au concours d'entrée à Poudlard, mais pour ça il va falloir réussir 4 épreuves (une par maison) pour prouver votre capacité à devenir le meilleur sorcier.

Comment ça marche ?

En se baladant dans les couloirs de l'entreprise, il faut trouver les 4 pièces qui renferment une épreuve. On s'enferme dans la pièce le temps de résoudre l'énigme, puis on obtient un code à rentrer dans une application web pour valider l'épreuve. Ce système permet à tout le monde de faire l'escape game en même temps, en faisant les épreuves sans ordre imposé. Chaque épreuve avait un mécanisme à activer dans le thème de la maison pour avoir le code : jeu de miroirs avec des lasers, cours de magie avec un sort à jeter validé par une caméra à détection de mouvement, décryptage de fichiers audio, écrans invisibles avec des lunettes révélatrices, etc.
