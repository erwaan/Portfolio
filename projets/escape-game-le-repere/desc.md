# Le projet
"Le Repère" est la suite de l'escape game "Séquestrés". Après s'être enfuit de justesse d'une secte dont vous aliez être le sacrifice, vous trouver un repère pour vous cacher le temps que le jour revienne. Mais tout semble avoir été calculé et cet endroit qui semblait être un heureux hasard n'est pas si sûr qu'il n'y parrait.
Pendant 1h30, il va falloir déjouer les pièges de ce repère pour s'enfuire avant le piège ne se referme sur vous.

# Comment ça marche ?
Ce projet a nécessité 8 caméras infrarouge connectées, 5 raspberry pi et un serveur local avec une application web pour contrôler tous les mécanismes à distance. Le point central du jeu : un couloir avec 90 lasers réparties en 8 rangées à éteindre pour retrouver la sortie, le tout agrémenté de choix et dilème moraux qui influence la suite de l'histoire et le sort des autre cohéquipiers.

# Outil et techno
Python, flask, html/css/js, Rasperry Pi, ESP32, flux vidéo RTSP, régie audio et vidéo
